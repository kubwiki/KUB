# Split-Reel

Split-Reel macht aus einem Querformat-Video, in dem du etwas erklärst, ein Hochformat-Reel für Instagram, TikTok oder YouTube Shorts – im Magazin-Look.

- Unten läuft dein Video als Karte.
- In der Mitte stehen die Untertitel, Schlüsselwörter in Gold.
- Oben erscheinen große Worte, Fotos mit Gold-Wischkante und Stempel zum Gesagten – genau in dem Moment, in dem du das Wort sagst.
- Darüber liegen Filmkorn, Vignette und ein goldener Lichtschimmer.
- Ganz unten bleibt Platz frei, weil Instagram dort selbst Text einblendet.

Kurze Videos nimmt es komplett, aus langen holt es eine Kernaussage von 30 bis 45 Sekunden. Es kostet nichts, alles läuft auf deinem eigenen Rechner, nichts wird hochgeladen und es wird nichts per KI erzeugt. Fotos kommen aus deinem Video, von dir oder als freie CC0-Bilder.

## So benutzt du es

Du brauchst Claude Code auf dem Mac. Dann sagst du zum Beispiel:

- "Mach aus diesem Video ein Split-Reel" und gibst die Videodatei oder einen YouTube-Link.
- "Was kann Split-Reel?", wenn du eine kurze Erklärung willst.

Beim ersten Mal installiert Claude einmalig ein paar kostenlose Werkzeuge. Das fertige Reel liegt danach auf deinem Schreibtisch.
